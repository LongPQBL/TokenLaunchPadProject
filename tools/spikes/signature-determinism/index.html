Signature determinism

Does this wallet produce the same signature every time for the same message?

Why this matters. The trading session wallet's private key is derived from this signature (spec §7.2). If a wallet signs the same message differently each time, a user who clears their browser data would derive a different wallet and lose access to the funds in the old one.

Run this locally only. The page shows signatures and derived addresses, never a private key, but a signature over this exact message is the session key — treat this tab like a wallet.

How to run
  1. Open this page in the wallet's browser, or with the extension installed.
  2. Press Sign 5 times and approve each request. Do not change accounts between them.
  3. Note the verdict, then repeat in the next wallet.
  4. A wallet that disconnects and reconnects between runs must still derive the same address — run it twice to be sure.
